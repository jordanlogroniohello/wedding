# LED wall: the monogram screen (backup)

An online copy of the LED wall's idle screen, as of 2026-11-26.

- **To play it:** open `index.html` in Google Chrome and press F for full screen. `README.txt` lists the keys (H shows them on screen). Everything works offline.
- **`source/wedding/`:** a copy of the code and pictures it is built from. The working copy lives in the gzdnimation project at `src/wedding/`. Rebuild it there with `node src/wedding/stage/build.mjs --dj`, which makes `out/wedding/led-wall-dj/` and the zip. The scenes' videos are rendered there with `--render`.
